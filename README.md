# 🛒 Business Case: Turnaround & Benchmarking (Grupo DIA vs Mercadona)

## 🎯 Sobre el Proyecto
Este repositorio contiene un **Executive Summary** interactivo diseñado para ilustrar un plan de reestructuración corporativa (*Turnaround*). El panel analiza la situación de estrés financiero de Grupo DIA y propone un plan de choque (desinversión y Capex logístico) utilizando a Mercadona como *Benchmark* de eficiencia operativa.

Como analista, mi objetivo con este proyecto es demostrar mi capacidad para resolver problemas financieros complejos mediante el orden, el análisis de datos (extracción de Cuentas Anuales de la CNMV y Registros Mercantiles) y la visualización ejecutiva. 

## 📊 Estructura del Análisis
*   **Diagnóstico de Situación (As-Is):** Análisis de apalancamiento (Deuda Neta / EBITDA) y visualización del Muro de Vencimientos (*Debt Maturity Wall*).
*   **Benchmarking Competitivo:** Comparativa directa de KPIs críticos (Margen EBIT, Rotación de Inventario, Ventas/FTE).
*   **Plan de Contingencia Recomendado:** 
    *   *Fase 1:* Carve-Out y desinversión de activos no-core para generar liquidez inmediata.
    *   *Fase 2:* Reasignación de capital hacia la automatización logística y el modelo de proximidad de alta rotación.
*   **Arquitectura de Datos:** El panel visual actúa como *front-end*, pero el análisis subyacente está estructurado para un modelo relacional en Power BI (Cash flow forecasting a 13 semanas).

## 🛠️ Tecnologías Utilizadas
*   **Frontend:** HTML5, CSS3 (Tailwind CSS - enfocado a diseño corporativo institucional).
*   **Data Visualization:** Chart.js (Gráficos de barras apiladas para perfil de deuda y benchmarking comparativo).

## ⚖️ Auditoría de Datos y Metodología (Disclaimer)
Este panel es un Business Case académico-profesional. Las métricas (KPIs), gráficas y muros de vencimientos son representaciones simplificadas y modelizadas basadas en la casuística histórica del sector retail español pre-exclusión de bolsa. No constituye asesoramiento financiero ni refleja la situación contable en tiempo real a fecha de hoy.
